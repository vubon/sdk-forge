## Installation

### Prerequisites

- **Node.js 18+** (for running the SDK)
- **npm** or **yarn** package manager
- **TypeScript 4.9+** (optional, for TypeScript projects)

### Install Generated SDK

```bash
cd ./sdks/typescript/my-api-sdk/my-api-sdk
npm install
```

### Build the SDK

```bash
npm run build
```

This compiles TypeScript to JavaScript in the `dist/` directory.

### Install with Development Dependencies

```bash
npm install --include=dev
```

This installs:
- SDK package
- Testing dependencies (Jest, ts-jest)
- Development tools (ESLint, Prettier)
- TypeScript compiler

## Basic Usage

### Import and Initialize

**TypeScript:**
```typescript
import { MyApiSdk } from './my-api-sdk';

// Initialize client
const client = new MyApiSdk({
  baseUrl: 'https://api.example.com/v1',
  apiKey: 'your-api-key'  // If using API key auth
});
```

**JavaScript (ESM):**
```javascript
import { MyApiSdk } from './my-api-sdk';

const client = new MyApiSdk({
  baseUrl: 'https://api.example.com/v1',
  apiKey: 'your-api-key'
});
```

**JavaScript (CommonJS):**
```javascript
const { MyApiSdk } = require('./my-api-sdk');

const client = new MyApiSdk({
  baseUrl: 'https://api.example.com/v1',
  apiKey: 'your-api-key'
});
```

### Make API Calls

```typescript
// Using API modules (organized by OpenAPI tags)
import { MyApiSdk, UsersApi } from './my-api-sdk';

const client = new MyApiSdk({
  baseUrl: 'https://api.example.com/v1',
  apiKey: 'your-api-key'
});

const usersApi = new UsersApi(client);

// Make API call
const users = await usersApi.listUsers();
console.log(users);
```

### Handle Responses

```typescript
import { MyApiSdk, ApiException } from './my-api-sdk';

const client = new MyApiSdk({
  baseUrl: 'https://api.example.com/v1',
  apiKey: 'your-api-key'
});

try {
  const users = await client.request({
    method: 'GET',
    url: '/users'
  });
  console.log('Users:', users);
} catch (error) {
  if (error instanceof ApiException) {
    console.error(`API Error: ${error.statusCode} - ${error.message}`);
  } else {
    console.error('Unexpected error:', error);
  }
}
```

## HTTP Libraries

SDK Forge supports multiple HTTP client libraries for TypeScript/JavaScript SDKs.

### Available Libraries

- **`axios`** (default) - Popular promise-based HTTP client
- **`fetch`** - Native browser/Node.js Fetch API
- **`node-fetch`** - Lightweight Fetch API implementation for Node.js
- **`ky`** - Tiny and elegant HTTP client based on Fetch API

### Generate with Specific Library

```bash
sdk-forge generate \
  --schema api.yaml \
  --lang typescript \
  --http-lib fetch \
  --name my-sdk \
  --output ./sdks
```

### Using Different Libraries

**axios (default):**
```typescript
import { MySdkClient } from './my-sdk';

const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1'
});
```

**fetch:**
```typescript
import { MySdkClient } from './my-sdk';

// fetch is available natively in modern browsers and Node.js 18+
const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1'
});
```

**node-fetch:**
```typescript
import { MySdkClient } from './my-sdk';
import fetch from 'node-fetch';

const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1',
  // node-fetch is used automatically when available
});
```

**ky:**
```typescript
import { MySdkClient } from './my-sdk';
import ky from 'ky';

const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1',
  // ky is used automatically when available
});
```

## Retry Mechanism

When retry is enabled during SDK generation, the TypeScript SDK automatically retries failed requests.

### Enable Retry During Generation

```bash
sdk-forge generate \
  --schema api.yaml \
  --lang typescript \
  --name my-sdk \
  --retry-enabled \
  --retry-max-attempts 3 \
  --retry-strategy exponential \
  --output ./sdks
```

### Using Retry in Generated SDK

```typescript
import { MySdkClient } from './my-sdk';

// Client is initialized with retry configuration
const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1',
  apiKey: 'your-key'
});

// Retry happens automatically on retryable errors
try {
  const users = await client.request({
    method: 'GET',
    url: '/users'
  });
} catch (error) {
  // Retry exhausted - handle final error
  console.error('Request failed after retries:', error);
}
```

### Retry Configuration

The retry configuration is set during SDK generation and cannot be changed at runtime. To modify retry behavior, regenerate the SDK with different retry flags.

**Retry Strategies:**
- **exponential**: Delay increases exponentially (1s, 2s, 4s, 8s...)
- **linear**: Delay increases linearly (1s, 2s, 3s, 4s...)
- **fixed**: Constant delay between retries (1s, 1s, 1s...)

**Default Retryable Status Codes:** 429, 500, 502, 503, 504

## Advanced Usage

### Module Systems (ESM/CommonJS)

The generated SDK supports both ESM and CommonJS module systems.

**ESM (package.json with `"type": "module"`):**
```typescript
import { MySdkClient } from './my-sdk';
```

**CommonJS:**
```javascript
const { MySdkClient } = require('./my-sdk');
```

### TypeScript Type Safety

```typescript
import { MySdkClient, User, CreateUserRequest } from './my-sdk';

const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1'
});

// Type-safe API calls
const userRequest: CreateUserRequest = {
  name: 'John Doe',
  email: 'john@example.com'
};

const user: User = await client.createUser({ body: userRequest });
```

### Error Handling

```typescript
import { MySdkClient, ApiException, NetworkException } from './my-sdk';

const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1'
});

try {
  const user = await client.getUser({ id: 123 });
} catch (error) {
  if (error instanceof ApiException) {
    console.error(`API Error: ${error.statusCode} - ${error.message}`);
    console.error('Response:', error.response);
  } else if (error instanceof NetworkException) {
    console.error('Network Error:', error.message);
    console.error('Cause:', error.cause);
  } else {
    console.error('Unexpected error:', error);
  }
}
```

### Working with Models

```typescript
import { MySdkClient, User } from './my-sdk';

const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1'
});

// Models are TypeScript interfaces/types
interface User {
  id: number;
  name: string;
  email: string;
}

// Use in API calls
const newUser: User = {
  id: 1,
  name: 'John Doe',
  email: 'john@example.com'
};

const createdUser = await client.createUser({ body: newUser });
```

### Pagination

```typescript
// If API supports pagination
let page = 1;
const limit = 10;

while (true) {
  const response = await client.listUsers({
    page,
    limit
  });
  
  const users = response as User[];
  
  if (!users || users.length === 0) {
    break;
  }
  
  // Process users
  for (const user of users) {
    console.log(user);
  }
  
  page++;
}
```

### Custom Request Configuration

```typescript
const client = new MySdkClient({
  baseUrl: 'https://api.example.com/v1',
  timeout: 30000, // 30 seconds
  headers: {
    'X-Custom-Header': 'value'
  }
});
```

## Troubleshooting

### Import Errors

**Problem:** `Cannot find module './my-api-sdk'` or `ERR_MODULE_NOT_FOUND`

**Solution:**
```bash
# Ensure you're in the correct directory
cd ./sdks/typescript/my-api-sdk/my-api-sdk

# Install dependencies
npm install

# Build the SDK
npm run build

# For ESM, ensure package.json has "type": "module"
```

### TypeScript Compilation Errors

**Problem:** Type errors when using the SDK

**Solution:**
- Ensure TypeScript version matches the SDK's target version
- Check `tsconfig.json` includes proper module resolution
- Verify all dependencies are installed: `npm install`

### Module Resolution Issues

**Problem:** `Cannot find module 'axios'` or similar HTTP library errors

**Solution:**
```bash
# Install the required HTTP library
npm install axios  # or fetch, node-fetch, ky

# Verify it's in package.json dependencies
```

### ESM/CommonJS Compatibility

**Problem:** `SyntaxError: Cannot use import statement outside a module`

**Solution:**
- For ESM: Ensure `package.json` has `"type": "module"`
- For CommonJS: Use `require()` instead of `import`
- Check Node.js version (18+ recommended for native ESM)

### Authentication Not Working

**Problem:** API returns 401 Unauthorized

**Solution:**
- Verify API key/token is correct
- Check authentication method matches OpenAPI schema
- Ensure credentials are passed correctly to client constructor
- Verify headers are being sent (check network tab)

### Retry Not Working

**Problem:** Requests not retrying on failures

**Solution:**
- Verify SDK was generated with `--retry-enabled` flag
- Check retryable status codes include the error code you're seeing
- Review retry configuration in generated client code
- Ensure error is a retryable error (network error or retryable status code)

### Jest Test Failures

**Problem:** Tests fail with module resolution or ESM errors

**Solution:**
- Check `jest.config.cjs` is properly configured for ESM
- Verify `ts-jest` is installed and configured
- Ensure test files use `.js` extensions in imports (for ESM compatibility)
- Check `package.json` has `"type": "module"` if using ESM

## Best Practices

1. **Use TypeScript for Type Safety**
   ```typescript
   // Enable strict mode in tsconfig.json
   {
     "compilerOptions": {
       "strict": true,
       "esModuleInterop": true
     }
   }
   ```

2. **Store Credentials Securely**
   ```typescript
   const client = new MySdkClient({
     baseUrl: process.env.API_BASE_URL || 'https://api.example.com/v1',
     apiKey: process.env.API_KEY || ''
   });
   ```

3. **Handle Errors Properly**
   ```typescript
   try {
     const response = await client.getUser({ id: 123 });
   } catch (error) {
     if (error instanceof ApiException) {
       if (error.statusCode === 404) {
         console.log('User not found');
       } else if (error.statusCode >= 500) {
         console.log('Server error, retry later');
       }
     }
   }
   ```

4. **Use Async/Await**
   ```typescript
   // Good: Using async/await
   async function fetchUsers() {
     const users = await client.listUsers();
     return users;
   }
   
   // Avoid: Using promises directly
   client.listUsers().then(users => {
     // ...
   });
   ```

5. **Leverage TypeScript Types**
   ```typescript
   import { User, CreateUserRequest } from './my-sdk';
   
   function createUser(data: CreateUserRequest): Promise<User> {
     return client.createUser({ body: data });
   }
   ```

6. **Use ESLint and Prettier**
   ```bash
   # Run linting
   npm run lint
   
   # Format code
   npm run format
   ```
