## Installation

### Prerequisites

- **Go 1.24+** (1.24 or 1.25)
- **Go modules** enabled

### Install Generated SDK

```bash
cd ./sdks/go/my-api-client
go mod download
```

### Use in Your Project

```go
import "github.com/example/my-api-client"
```

Or if using a local path:

```go
import "./sdks/go/my-api-client"
```

## Basic Usage

### Initialize Client

```go
package main

import (
    "fmt"
    "github.com/example/my-api-client"
)

func main() {
    // Initialize client
    client := myapiclient.NewMyApiClient("https://api.example.com/v1")
    
    // Set authentication
    client.ApiKey = "your-api-key"
    
    // Make API calls
    data, err := client.ListUsers()
    if err != nil {
        panic(err)
    }
    
    fmt.Println(string(data))
}
```

### Handle Responses

```go
data, err := client.ListUsers()
if err != nil {
    // Handle error
    fmt.Printf("Error: %v\n", err)
    return
}

// Process response
var users []User
if err := json.Unmarshal(data, &users); err != nil {
    fmt.Printf("Parse error: %v\n", err)
    return
}

fmt.Printf("Found %d users\n", len(users))
```

## Authentication

SDK Forge generates authentication fields based on your OpenAPI schema's `securitySchemes`.

### API Key

```go
client := myapiclient.NewMyApiClient("https://api.example.com/v1")
client.ApiKey = "your-api-key"
```

### Bearer Token

```go
client := myapiclient.NewMyApiClient("https://api.example.com/v1")
client.BearerToken = "your-token"
```

### Basic Authentication

```go
client := myapiclient.NewMyApiClient("https://api.example.com/v1")
client.Username = "user"
client.Password = "pass"
```

### OAuth2

```go
client := myapiclient.NewMyApiClient("https://api.example.com/v1")
client.OAuth2Token = "your-oauth-token"
```

### OpenID Connect

```go
client := myapiclient.NewMyApiClient("https://api.example.com/v1")
client.OpenIdConnectToken = "your-openid-token"
```

### Digest Authentication

```go
client := myapiclient.NewMyApiClient("https://api.example.com/v1")
client.Username = "user"
client.Password = "pass"
// Digest auth is automatically used when both username and password are provided
// and the OpenAPI schema specifies digest authentication
```

### Mutual TLS (mTLS)

```go
client := myapiclient.NewMyApiClient("https://api.example.com/v1")
// mTLS is configured via client certificates
// Requires additional SSL/TLS configuration
```

## HTTP Libraries

SDK Forge supports multiple HTTP libraries for Go SDKs.

### Available Libraries

- **`nethttp`** (default) - Standard library `net/http`
- **`resty`** - Simple HTTP and REST client
- **`gentleman`** - Plugin-driven HTTP client

### Generate with Specific Library

```bash
sdk-forge generate \
  --schema api.yaml \
  --lang go \
  --http-lib resty \
  --name my-sdk \
  --output ./sdks
```

### Using Different Libraries

**net/http (default):**
```go
import "github.com/example/my-sdk"

client := mysdk.NewMySdkClient("https://api.example.com/v1")
```

**resty:**
```go
import (
    "github.com/example/my-sdk"
    "github.com/go-resty/resty/v2"
)

// Custom resty client
restyClient := resty.New()
restyClient.SetTimeout(30 * time.Second)

client := mysdk.NewMySdkClient(
    "https://api.example.com/v1",
    mysdk.WithHTTPClient(restyClient),
)
```

**gentleman:**
```go
import (
    "github.com/example/my-sdk"
    "gopkg.in/h2non/gentleman.v2"
)

// Custom gentleman client
gentlemanClient := gentleman.New()
gentlemanClient.URL("https://api.example.com/v1")

client := mysdk.NewMySdkClient(
    "https://api.example.com/v1",
    mysdk.WithHTTPClient(gentlemanClient),
)
```

## Retry Mechanism

When retry is enabled during SDK generation, the Go SDK automatically retries failed requests.

### Enable Retry During Generation

```bash
sdk-forge generate \
  --schema api.yaml \
  --lang go \
  --name my-sdk \
  --retry-enabled \
  --retry-max-attempts 3 \
  --retry-strategy exponential \
  --output ./sdks
```

### Using Retry in Generated SDK

```go
package main

import (
    "fmt"
    "github.com/example/my-sdk"
)

func main() {
    // Client is initialized with retry configuration
    client := mysdk.NewMySdkClient("https://api.example.com/v1")
    client.ApiKey = "your-key"
    
    // Retry happens automatically on retryable errors
    data, err := client.ListUsers()
    if err != nil {
        // Retry exhausted - handle final error
        fmt.Printf("Request failed after retries: %v\n", err)
        return
    }
    
    fmt.Println(string(data))
}
```

### Retry Configuration

The retry configuration is set during SDK generation and cannot be changed at runtime. To modify retry behavior, regenerate the SDK with different retry flags.

**Retry Strategies:**
- **exponential**: Delay increases exponentially (1s, 2s, 4s, 8s...)
- **linear**: Delay increases linearly (1s, 2s, 3s, 4s...)
- **fixed**: Constant delay between retries (1s, 1s, 1s...)

**Default Retryable Status Codes:** 429, 500, 502, 503, 504

## Running Tests

### Run All Tests

```bash
cd ./sdks/go/my-api-client
go test ./...
```

### Run Specific Test File

```bash
go test ./client_test.go
```

### Run with Verbose Output

```bash
go test -v ./...
```

### Run with Coverage

```bash
go test -cover ./...
```

### Test Structure

Generated tests include:
- **Client Tests** (`client_test.go`) - Client initialization and configuration
- **Authentication Tests** (`auth_test.go`) - All authentication methods
- **API Method Tests** (`api_test.go`) - API endpoint calls
- **Model Tests** (`models_test.go`) - Data model serialization/deserialization

## Advanced Usage

### Custom HTTP Client

```go
import (
    "net/http"
    "time"
    "github.com/example/my-sdk"
)

// Create custom HTTP client with timeouts
httpClient := &http.Client{
    Timeout: 30 * time.Second,
    Transport: &http.Transport{
        MaxIdleConns:        100,
        IdleConnTimeout:    90 * time.Second,
        DisableCompression: false,
    },
}

client := mysdk.NewMySdkClient(
    "https://api.example.com/v1",
    mysdk.WithHTTPClient(httpClient),
)
```

### Error Handling

```go
import (
    "errors"
    "github.com/example/my-sdk"
)

data, err := client.GetUser(userID)
if err != nil {
    var apiErr *mysdk.ApiError
    if errors.As(err, &apiErr) {
        switch apiErr.StatusCode {
        case 404:
            fmt.Println("User not found")
        case 500:
            fmt.Println("Server error, retry later")
        default:
            fmt.Printf("API error: %d - %s\n", apiErr.StatusCode, apiErr.Message)
        }
    } else {
        fmt.Printf("Unexpected error: %v\n", err)
    }
    return
}
```

### Working with Models

```go
import (
    "encoding/json"
    "github.com/example/my-sdk"
)

// Create model instance
user := mysdk.User{
    ID:   1,
    Name: "John Doe",
    Email: "john@example.com",
}

// Marshal to JSON
userJSON, err := json.Marshal(user)
if err != nil {
    panic(err)
}

// Use in API calls
response, err := client.CreateUser(userJSON)
```

### Context Support

```go
import (
    "context"
    "time"
    "github.com/example/my-sdk"
)

ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
defer cancel()

// If SDK supports context (depends on HTTP library)
data, err := client.ListUsersWithContext(ctx)
```

### Pagination

```go
page := 1
for {
    data, err := client.ListUsers(page, 10)
    if err != nil {
        break
    }
    
    var users []User
    if err := json.Unmarshal(data, &users); err != nil {
        break
    }
    
    if len(users) == 0 {
        break
    }
    
    // Process users
    for _, user := range users {
        fmt.Println(user)
    }
    
    page++
}
```

## Troubleshooting

### Module Import Errors

**Problem:** `cannot find package "github.com/example/my-api-client"`

**Solution:**
```bash
# If using replace directive in go.mod
go mod edit -replace github.com/example/my-api-client=./sdks/go/my-api-client

# Or use local import
import "./sdks/go/my-api-client"
```

### Authentication Not Working

**Problem:** API returns 401 Unauthorized

**Solution:**
- Verify API key/token is correct
- Check authentication method matches OpenAPI schema
- Ensure credentials are set before making API calls

### HTTP Library Issues

**Problem:** Import errors for HTTP library

**Solution:**
- Install required HTTP library: `go get github.com/go-resty/resty/v2` (for resty)
- Check SDK was generated with correct `--http-lib` flag
- Verify `go.mod` includes required dependencies

### Retry Not Working

**Problem:** Requests not retrying on failures

**Solution:**
- Verify SDK was generated with `--retry-enabled` flag
- Check retryable status codes include the error code you're seeing
- Review retry configuration in generated client code

## Best Practices

1. **Use Go Modules**
   ```bash
   go mod init my-project
   go mod tidy
   ```

2. **Store Credentials Securely**
   ```go
   import "os"
   
   client := mysdk.NewMySdkClient("https://api.example.com/v1")
   client.ApiKey = os.Getenv("API_KEY")
   ```

3. **Handle Errors Properly**
   ```go
   data, err := client.ListUsers()
   if err != nil {
       // Always check errors
       return fmt.Errorf("failed to list users: %w", err)
   }
   ```

4. **Use Context for Timeouts**
   ```go
   ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
   defer cancel()
   // Use context in requests if supported
   ```

5. **Close Resources**
   ```go
   // If using custom HTTP client with connections
   defer httpClient.CloseIdleConnections()
   ```
