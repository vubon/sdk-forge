## Installation

### Prerequisites

- **Python 3.11+** (3.11, 3.12, 3.13, or 3.14)
- **pip** package manager

### Install Generated SDK

```bash
cd ./sdks/python/my-api-sdk
pip install -e .
```

### Install with Development Dependencies

```bash
pip install -e ".[dev]"
```

This installs:
- SDK package
- Testing dependencies (pytest, etc.)
- Development tools

## Basic Usage

### Import and Initialize

```python
from my_api_sdk import MyApiSdk

# Initialize client
client = MyApiSdk(
    base_url="https://api.example.com/v1",
    apiKey="your-api-key"  # If using API key auth
)
```

### Make API Calls

```python
# Direct method calls
response = client.list_users()
users = response.json()

# Or use API modules (if organized by tags)
users_api = client.get_users_api()
users = users_api.list_users()
```

### Handle Responses

```python
try:
    response = client.list_users()
    data = response.json()
    print(f"Users: {data}")
except Exception as e:
    print(f"Error: {e}")
```

## Authentication

SDK Forge generates authentication methods based on your OpenAPI schema's `securitySchemes`.

### API Key

```python
client = MyApiSdk(
    base_url="https://api.example.com/v1",
    apiKey="your-api-key"
)
```

### Bearer Token

```python
client = MyApiSdk(
    base_url="https://api.example.com/v1",
    bearer_token="your-token"
)
```

### Basic Authentication

```python
client = MyApiSdk(
    base_url="https://api.example.com/v1",
    username="user",
    password="pass"
)
```

### OAuth2

```python
client = MyApiSdk(
    base_url="https://api.example.com/v1",
    oauth2_token="your-oauth-token"
)
```

### OpenID Connect

```python
client = MyApiSdk(
    base_url="https://api.example.com/v1",
    openIdConnect_token="your-openid-token"
)
```

### Digest Authentication

```python
client = MyApiSdk(
    base_url="https://api.example.com/v1",
    username="user",
    password="pass"
)
# Digest auth is automatically used when both username and password are provided
# and the OpenAPI schema specifies digest authentication
```

### Mutual TLS (mTLS)

```python
client = MyApiSdk(
    base_url="https://api.example.com/v1",
    # mTLS is configured via client certificates
    # Requires additional SSL/TLS configuration
)
```

## HTTP Libraries

SDK Forge supports multiple HTTP libraries for Python SDKs.

### Available Libraries

- **`requests`** (default) - Simple and popular
- **`httpx`** - Modern async/sync HTTP client
- **`aiohttp`** - Async HTTP client
- **`urllib3`** - Low-level HTTP library

### Generate with Specific Library

```bash
sdk-forge generate \
  --schema api.yaml \
  --lang python \
  --http-lib httpx \
  --name my-sdk \
  --output ./sdks
```

### Using Different Libraries

**requests (default):**
```python
from my_sdk import MySdkClient

client = MySdkClient(base_url="https://api.example.com/v1")
```

**httpx:**
```python
from my_sdk import MySdkClient
import httpx

# httpx client supports both sync and async
client = MySdkClient(
    base_url="https://api.example.com/v1",
    http_client=httpx.Client()  # Sync
    # or
    # http_client=httpx.AsyncClient()  # Async
)
```

**aiohttp (async):**
```python
from my_sdk import MySdkClient
import aiohttp

async def main():
    async with aiohttp.ClientSession() as session:
        client = MySdkClient(
            base_url="https://api.example.com/v1",
            http_client=session
        )
        response = await client.list_users()
```

## Retry Mechanism

When retry is enabled during SDK generation, the Python SDK automatically retries failed requests.

### Enable Retry During Generation

```bash
sdk-forge generate \
  --schema api.yaml \
  --lang python \
  --name my-sdk \
  --retry-enabled \
  --retry-max-attempts 3 \
  --retry-strategy exponential \
  --output ./sdks
```

### Using Retry in Generated SDK

```python
from my_sdk import MySdkClient

# Client is initialized with retry configuration
client = MySdkClient(
    base_url="https://api.example.com/v1",
    api_key="your-key"
)

# Retry happens automatically on retryable errors
try:
    users = client.list_users()
except Exception as e:
    # Retry exhausted - handle final error
    print(f"Request failed after retries: {e}")
```

### Retry Configuration

The retry configuration is set during SDK generation and cannot be changed at runtime. To modify retry behavior, regenerate the SDK with different retry flags.

**Retry Strategies:**
- **exponential**: Delay increases exponentially (1s, 2s, 4s, 8s...)
- **linear**: Delay increases linearly (1s, 2s, 3s, 4s...)
- **fixed**: Constant delay between retries (1s, 1s, 1s...)

**Default Retryable Status Codes:** 429, 500, 502, 503, 504

## Running Tests

### Install Test Dependencies

```bash
cd ./sdks/python/my-api-sdk
pip install -e ".[dev]"
```

### Run All Tests

```bash
pytest tests/
```

### Run Specific Test File

```bash
pytest tests/test_client.py
```

### Run with Coverage

```bash
pytest --cov=my_api_sdk tests/
```

### Test Structure

Generated tests include:
- **Client Tests** (`test_client.py`) - Client initialization and configuration
- **Authentication Tests** (`test_auth.py`) - All authentication methods
- **API Method Tests** (`test_api_methods.py`) - API endpoint calls
- **Model Tests** (`test_models.py`) - Data model serialization/deserialization

## Advanced Usage

### Custom HTTP Client Configuration

```python
import requests
from my_sdk import MySdkClient

# Create custom session with timeouts
session = requests.Session()
session.timeout = 30

client = MySdkClient(
    base_url="https://api.example.com/v1",
    http_client=session
)
```

### Error Handling

```python
from my_sdk import MySdkClient, ApiException

client = MySdkClient(base_url="https://api.example.com/v1")

try:
    response = client.get_user(user_id=123)
except ApiException as e:
    print(f"API Error: {e.status_code} - {e.message}")
except Exception as e:
    print(f"Unexpected error: {e}")
```

### Working with Models

```python
from my_sdk import MySdkClient, User

client = MySdkClient(base_url="https://api.example.com/v1")

# Create model instance
user = User(
    id=1,
    name="John Doe",
    email="john@example.com"
)

# Use in API calls
response = client.create_user(user)
```

### Pagination

```python
# If API supports pagination
page = 1
while True:
    response = client.list_users(page=page, limit=10)
    users = response.json()
    
    if not users:
        break
    
    # Process users
    for user in users:
        print(user)
    
    page += 1
```

## Troubleshooting

### Import Errors

**Problem:** `ModuleNotFoundError: No module named 'my_api_sdk'`

**Solution:**
```bash
# Install the SDK
cd ./sdks/python/my-api-sdk
pip install -e .
```

### Authentication Not Working

**Problem:** API returns 401 Unauthorized

**Solution:**
- Verify API key/token is correct
- Check authentication method matches OpenAPI schema
- Ensure credentials are passed correctly to client constructor

### HTTP Library Issues

**Problem:** Import errors for HTTP library

**Solution:**
- Install required HTTP library: `pip install requests` (or httpx, aiohttp, urllib3)
- Check SDK was generated with correct `--http-lib` flag

### Retry Not Working

**Problem:** Requests not retrying on failures

**Solution:**
- Verify SDK was generated with `--retry-enabled` flag
- Check retryable status codes include the error code you're seeing
- Review retry configuration in generated client code

## Best Practices

1. **Use Virtual Environments**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # or
   venv\Scripts\activate  # Windows
   ```

2. **Store Credentials Securely**
   ```python
   import os
   
   client = MySdkClient(
       base_url="https://api.example.com/v1",
       apiKey=os.getenv("API_KEY")
   )
   ```

3. **Handle Errors Properly**
   ```python
   try:
       response = client.list_users()
   except ApiException as e:
       if e.status_code == 404:
           print("Resource not found")
       elif e.status_code >= 500:
           print("Server error, retry later")
   ```

4. **Use Type Hints**
   ```python
   from typing import List
   from my_sdk import MySdkClient, User
   
   def get_all_users(client: MySdkClient) -> List[User]:
       return client.list_users()
   ```
