## Installation

### Prerequisites

- **PHP 8.0+** (8.0, 8.1, 8.2, or 8.3)
- **Composer** package manager

### Install Generated SDK

```bash
cd ./sdks/php/my-api-sdk/PascalCaseName
composer install
```

The SDK uses PSR-4 autoloading, so Composer will automatically set up the autoloader.

### Verify Installation

```bash
composer dump-autoload
php -r "require 'vendor/autoload.php'; echo 'Autoloader working!';"
```

## Basic Usage

### Require Autoloader

```php
<?php
require_once 'vendor/autoload.php';

use Vendor\MyApiSdk\MyApiSdk;
use Vendor\MyApiSdk\Api\UsersApi;
```

### Initialize Client

```php
// Initialize client
$client = new MyApiSdk(
    baseUrl: "https://api.example.com/v1",
    options: ['apiKey' => 'your-api-key']
);
```

### Use API Classes

```php
// API classes are organized by tags
$usersApi = new UsersApi($client);
$response = $usersApi->listUsers();
```

### Handle Responses

```php
try {
    $usersApi = new UsersApi($client);
    $response = $usersApi->listUsers();
    
    // Response is an array
    foreach ($response as $user) {
        echo $user['name'] . "\n";
    }
} catch (\Vendor\MyApiSdk\Exceptions\ApiException $e) {
    echo "API Error: " . $e->getMessage() . "\n";
    echo "Status Code: " . $e->getCode() . "\n";
}
```

## Authentication

SDK Forge generates authentication support based on your OpenAPI schema's `securitySchemes`.

### API Key

```php
$client = new MyApiSdk(
    baseUrl: "https://api.example.com/v1",
    options: ['apiKey' => 'your-api-key']
);
```

### Bearer Token

```php
$client = new MyApiSdk(
    baseUrl: "https://api.example.com/v1",
    options: ['bearer_token' => 'your-token']
);
```

### Basic Authentication

```php
$client = new MyApiSdk(
    baseUrl: "https://api.example.com/v1",
    options: [
        'username' => 'user',
        'password' => 'pass'
    ]
);
```

### OAuth2

```php
$client = new MyApiSdk(
    baseUrl: "https://api.example.com/v1",
    options: ['oauth2_token' => 'your-oauth-token']
);
```

### OpenID Connect

```php
$client = new MyApiSdk(
    baseUrl: "https://api.example.com/v1",
    options: ['openIdConnect_token' => 'your-openid-token']
);
```

## HTTP Libraries

SDK Forge currently supports Guzzle HTTP client for PHP SDKs.

### Guzzle (Default)

Guzzle is the default and only HTTP library for PHP SDKs. It's automatically included via Composer.

### Custom Guzzle Client

```php
use GuzzleHttp\Client;
use Vendor\MyApiSdk\MyApiSdk;

// Create custom Guzzle client
$guzzleClient = new Client([
    'timeout' => 30,
    'verify' => true, // SSL verification
]);

$client = new MyApiSdk(
    baseUrl: "https://api.example.com/v1",
    options: [
        'http_client' => $guzzleClient,
        'apiKey' => 'your-api-key'
    ]
);
```

## Retry Mechanism

When retry is enabled during SDK generation, the PHP SDK automatically retries failed requests.

### Enable Retry During Generation

```bash
sdk-forge generate \
  --schema api.yaml \
  --lang php \
  --name my-sdk \
  --retry-enabled \
  --retry-max-attempts 3 \
  --retry-strategy exponential \
  --output ./sdks
```

### Using Retry in Generated SDK

```php
<?php
require_once 'vendor/autoload.php';

use Vendor\MySdk\MySdk;
use Vendor\MySdk\Api\UsersApi;
use Vendor\MySdk\Exceptions\ApiException;

// Client is initialized with retry configuration
$client = new MySdk(
    baseUrl: "https://api.example.com/v1",
    options: ['apiKey' => 'your-key']
);

$usersApi = new UsersApi($client);

// Retry happens automatically on retryable errors
try {
    $users = $usersApi->listUsers();
} catch (ApiException $e) {
    // Retry exhausted - handle final error
    echo "Request failed after retries: " . $e->getMessage() . "\n";
}
```

### Retry Configuration

The retry configuration is set during SDK generation and cannot be changed at runtime. To modify retry behavior, regenerate the SDK with different retry flags.

**Retry Strategies:**
- **exponential**: Delay increases exponentially (1s, 2s, 4s, 8s...)
- **linear**: Delay increases linearly (1s, 2s, 3s, 4s...)
- **fixed**: Constant delay between retries (1s, 1s, 1s...)

**Default Retryable Status Codes:** 429, 500, 502, 503, 504

## Running Tests

### Install Test Dependencies

```bash
cd ./sdks/php/my-api-sdk/PascalCaseName
composer install
```

### Run All Tests

```bash
vendor/bin/phpunit
```

### Run Specific Test File

```bash
vendor/bin/phpunit tests/ClientTest.php
```

### Run with Coverage

```bash
vendor/bin/phpunit --coverage-html coverage/
```

### Test Structure

Generated tests include:
- **Client Tests** (`ClientTest.php`) - Client initialization and configuration
- **Authentication Tests** (`AuthTest.php`) - All authentication methods
- **API Method Tests** (`ApiMethodsTest.php`) - API endpoint calls
- **Model Tests** (`ModelsTest.php`) - Data model serialization/deserialization

## Advanced Usage

### Custom HTTP Client Configuration

```php
use GuzzleHttp\Client;
use GuzzleHttp\HandlerStack;
use GuzzleHttp\Middleware;
use Vendor\MySdk\MySdk;

// Create custom handler stack with middleware
$stack = HandlerStack::create();
$stack->push(Middleware::mapRequest(function ($request) {
    // Add custom headers
    return $request->withHeader('X-Custom-Header', 'value');
}));

$guzzleClient = new Client([
    'handler' => $stack,
    'timeout' => 30,
]);

$client = new MySdk(
    baseUrl: "https://api.example.com/v1",
    options: [
        'http_client' => $guzzleClient,
        'apiKey' => 'your-api-key'
    ]
);
```

### Error Handling

```php
use Vendor\MySdk\Exceptions\ApiException;

try {
    $response = $usersApi->getUserById(123);
} catch (ApiException $e) {
    $statusCode = $e->getCode();
    $message = $e->getMessage();
    $responseBody = $e->getResponseBody();
    
    switch ($statusCode) {
        case 404:
            echo "User not found\n";
            break;
        case 500:
            echo "Server error, retry later\n";
            break;
        default:
            echo "API error: {$statusCode} - {$message}\n";
    }
}
```

### Working with Models

```php
use Vendor\MySdk\Models\User;

// Create model instance
$user = new User();
$user->setId(1);
$user->setName('John Doe');
$user->setEmail('john@example.com');

// Use in API calls
$response = $usersApi->createUser($user->toArray());
```

### Pagination

```php
$page = 1;
while (true) {
    $response = $usersApi->listUsers(
        null, // status
        null, // category
        null, // tags
        null, // search
        $page, // page
        10     // limit
    );
    
    if (empty($response)) {
        break;
    }
    
    // Process users
    foreach ($response as $user) {
        echo $user['name'] . "\n";
    }
    
    $page++;
}
```

### Environment Variables

```php
$client = new MyApiSdk(
    baseUrl: getenv('API_BASE_URL') ?: 'https://api.example.com/v1',
    options: [
        'apiKey' => getenv('API_KEY')
    ]
);
```

## Troubleshooting

### Autoloader Errors

**Problem:** `Class "Vendor\MySdk\MySdk" not found`

**Solution:**
```bash
# Regenerate autoloader
composer dump-autoload

# Verify autoloader path
php -r "require 'vendor/autoload.php';"
```

### PSR-4 Namespace Issues

**Problem:** Classes not found even after `composer dump-autoload`

**Solution:**
- Verify `composer.json` has correct PSR-4 namespace mapping
- Check file structure matches namespace (e.g., `Vendor\MySdk` → `src/MySdk.php`)
- Ensure SDK was generated correctly

### Authentication Not Working

**Problem:** API returns 401 Unauthorized

**Solution:**
- Verify API key/token is correct
- Check authentication method matches OpenAPI schema
- Ensure credentials are passed in `options` array

### Composer Dependency Issues

**Problem:** `composer install` fails or dependencies missing

**Solution:**
```bash
# Clear cache and reinstall
composer clear-cache
composer install --no-cache

# Update dependencies
composer update
```

### Retry Not Working

**Problem:** Requests not retrying on failures

**Solution:**
- Verify SDK was generated with `--retry-enabled` flag
- Check retryable status codes include the error code you're seeing
- Review retry configuration in generated client code

## Best Practices

1. **Use Composer for Dependency Management**
   ```bash
   composer install
   composer update
   ```

2. **Store Credentials Securely**
   ```php
   $client = new MyApiSdk(
       baseUrl: "https://api.example.com/v1",
       options: ['apiKey' => $_ENV['API_KEY']]
   );
   ```

3. **Handle Errors Properly**
   ```php
   try {
       $response = $api->method();
   } catch (ApiException $e) {
       // Handle API errors
       logError($e->getMessage(), $e->getCode());
   } catch (\Exception $e) {
       // Handle unexpected errors
       logError($e->getMessage());
   }
   ```

4. **Use Type Hints (PHP 8.0+)**
   ```php
   function getUser(UsersApi $api, int $userId): array {
       return $api->getUserById($userId);
   }
   ```

5. **Follow PSR Standards**
   - PSR-4 autoloading (already configured)
   - PSR-12 coding style (PHP-CS-Fixer included)
   - PSR-1 basic coding standard
